# Security Policy | سیاست امنیتی

## فارسی
برای گزارش آسیب‌پذیری، اطلاعات حساس را در Issue عمومی منتشر نکنید. ابتدا از طریق راه ارتباطی توسعه‌دهنده در `postyekrooz.ir/plugins` تماس بگیرید و نسخه افزونه، نسخه WordPress/WooCommerce، مراحل بازتولید و اثر امنیتی را توضیح دهید.

نسخه 3.0.1 برای عملیات اصلی ارسال Local-only است. تنها قابلیت GitHub Updater برای بررسی `update.json` و دریافت بسته نسخه جدید به GitHub متصل می‌شود.

## English
Please do not disclose security-sensitive details in a public GitHub issue. Contact the maintainer first and include the plugin version, WordPress/WooCommerce versions, reproduction steps and impact.

The shipping operations core remains local-only. The GitHub updater is the only component that performs a public network request for version checks and update downloads.
