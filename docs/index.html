نصب و راه‌اندازی

برای سایت اصلی، ابتدا یک نسخه Staging داشته باشید. نصب افزونه مثل افزونه‌های استاندارد WordPress است.

Installation

Test on staging first. Installation follows the standard WordPress plugin flow.

ZIP را نصب کنید. از Plugins → Add New → Upload Plugin فایل را بارگذاری و فعال کنید.
Shipping Zone را تنظیم کنید. در WooCommerce → Settings → Shipping روش Mahex Shipping را به Zone اضافه کنید.
نرخ و بسته‌بندی را بسازید. از منوی ماهکس Ruleها و پروفایل‌های بسته را تعریف کنید.
یک Checkout واقعی تست کنید. مقصد، وزن، بسته‌بندی و هزینه نهایی را بررسی کنید.

بسته‌بندی و عملیات

برای هر محصول می‌توانید ابعاد، وزن، پروفایل بسته، انبار مبدا، زمان آماده‌سازی، No‑Mix و اطلاعات عملیاتی تعیین کنید.

۱. پروفایل بسته

کارتن/پاکت را با ابعاد، وزن خالی، سقف وزن، سقف تعداد، موجودی و قیمت ثبت کنید.

۲. تنظیم محصول

ابعاد محصول یا پروفایل، انبار، ارزش مرسوله و قواعد جداسازی را انتخاب کنید.

۳. Packing Engine

سیستم ترکیب بسته‌ها را محاسبه کرده و هزینه و عملیات را به سفارش متصل می‌کند.

بروزرسانی مستقیم از GitHub

نسخه 3.0.1 یک Update Channel عمومی دارد. WordPress فایل dist/update.json را با کش ۶ ساعته بررسی می‌کند و فقط اگر نسخه جدیدتر باشد آن را در صفحه Plugins نمایش می‌دهد.

حریم خصوصی: هسته نرخ، بسته‌بندی و عملیات Local‑only باقی می‌ماند. فقط بررسی نسخه و دانلود بسته بروزرسانی از Repository عمومی GitHub به شبکه نیاز دارد. با فیلتر hm_mahex_github_updates_enabled می‌توان Update Check را غیرفعال کرد.
add_filter( 'hm_mahex_github_updates_enabled', '__return_false' );
