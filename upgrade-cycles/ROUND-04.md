# دور چهارم — ثبت اولیه پیش از پیاده‌سازی

مبنای دور نسخه منتشرشده `3.6.0` و هدف برنامه‌ریزی‌شده `3.7.0` است.

دقیقاً ۱۰۰ معیار تازه، غیرتکراری و قابل ارزیابی پیش از کدنویسی ثبت شدند:

- [R04-001 تا R04-050: شمارش دوره‌ای و مغایرت‌گیری موجودی بسته‌بندی](ROUND-04-operations.md)
- [R04-051 تا R04-100: دریافت مرحله‌ای و کنترل کیفیت خرید ملزومات](ROUND-04-management.md)

هیچ معیار هنوز پیاده‌سازی‌شده محسوب نمی‌شود. وضعیت فقط پس از بازبینی کد، آزمون مستقل، نصب ZIP واقعی، WooCommerce در HPOS و کلاسیک، و آزمون مرورگر جریان‌های تغییرکرده کامل می‌شود.

محدودیت قطعی: همه شمارش‌ها، بازرسی‌ها و رسیدها ثبت دستی محلی‌اند. هیچ API ماهکس، webhook، صف API حمل، اتصال تأمین‌کننده یا ادعای تأیید دستگاه/واقعیت فیزیکی ساخته نمی‌شود.
