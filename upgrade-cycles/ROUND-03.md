## نتیجه واقعی

برنامه‌ریز موج‌های آفلاین روی سفارش واقعی ووکامرس ساخته شد: ظرفیت سفارش/بسته/وزن/زمان، داده نامعلوم، خوشه کم‌افشا، ترتیب قطعی، درگ‌ودراپ و صفحه‌کلید، snapshot نسخه‌دار، تشخیص رانش، چرخه حالت، قفل/revision، خروجی کم‌داده و privacy. این موج مسیر نقشه یا وضعیت شرکت حمل نیست.

کمپین نمونه‌برداری کیفیت بسته‌بندی با انتخاب قطعی محلی، الگوی نسخه‌دار، پاسخ سه‌حالته، مشاهده دستی، عیب و تصمیم، قرنطینه، بازبینی کاربر دوم، بازرسی مجدد، برد RTL، آمار توصیفی، CSV کم‌داده و برگه چاپ آفلاین ساخته شد. قرنطینه باز واقعاً پلمب دفتر تحویل محلی را مسدود می‌کند.

- backend واقعی: snapshot و رانش موج، چرخه کامل، privacy سفارش، کمپین روی سفارش‌های واقعی، قرنطینه، مانع عملیات و رفع با کاربر دوم.

## محدودیت‌ها

هیچ API ماهکس، webhook یا صف API شرکت حمل ساخته نشده است. ترتیب موج، زمان سفر، اجرای فیزیکی یا پذیرش شرکت حمل را اثبات نمی‌کند. مشاهده بازرسی، قرنطینه و رفع آن اظهار دستی کاربران مجاز است؛ چاپگر، دستگاه یا سرویس بیرونی آزمایش نشده است. هیچ فروشگاه زنده یا اقدام هزینه‌دار انجام نشده است.
