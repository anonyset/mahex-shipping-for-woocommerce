# دور سوم — ثبت اولیه پیش از پیاده‌سازی

مبنای دور: نسخه منتشرشده `3.5.0`؛ هدف برنامه‌ریزی‌شده: `3.6.0`.

در این نقطه دقیقاً ۱۰۰ معیار تازه، قابل ارزیابی و غیرتکراری ثبت شده‌اند و هنوز هیچ‌کدام پیاده‌سازی‌شده محسوب نمی‌شوند:

- [R03-001 تا R03-050: برنامه‌ریز آفلاین موج‌های ارسال](ROUND-03-operations.md)
- [R03-051 تا R03-100: کمپین نمونه‌برداری کیفیت بسته‌بندی](ROUND-03-management.md)

محدودیت قطعی هر دو جریان: هیچ API ماهکس، webhook، صف API شرکت حمل، مسیریابی نقشه یا ادعای تأیید فیزیکی/بیرونی ساخته نمی‌شود. موج فقط برنامه داخلی فروشگاه است و بازرسی کیفیت فقط مشاهده دستی کاربر مجاز را ثبت می‌کند.

وضعیت این دور فقط پس از پیاده‌سازی هر ۱۰۰ معیار، بازبینی کد، نصب ZIP واقعی، آزمون WooCommerce CRUD در HPOS و ذخیره کلاسیک، و آزمون مرورگر جریان‌های تغییرکرده به `completed` تبدیل می‌شود.
